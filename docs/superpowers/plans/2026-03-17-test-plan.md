# Plano de Testes — Claudinho (Inventory SaaS)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar a suíte de testes completa do sistema de inventário SaaS, cobrindo desde a fundação de segurança multi-tenant até os componentes de interface.

**Architecture:** Monólito modular com Clean Architecture. Testes seguem estritamente a camada que cobrem: unit (domain + application), integration (infrastructure/repositories) e e2e (presentation/controllers). Nenhum teste toca infraestrutura real fora do ambiente de integração dedicado.

**Tech Stack:** NestJS · Prisma · PostgreSQL · Redis · BullMQ · React + Vite · Jest (back-end) · Vitest + React Testing Library (front-end)

    const token = RefreshToken.create({ userId: 'user-1', role: 'gestor' })
    expect(token.isValid()).toBe(true)
  })

  it('should detect reuse of an already-rotated token as potential compromise', () => {
    const token = RefreshToken.create({ userId: 'user-1', role: 'gestor' })
    token.markAsRotated()
